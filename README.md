# Diabetes-Prediction-System
A modern, user-friendly web application built with Streamlit that predicts diabetes risk using machine learning. The application analyzes patient health metrics and provides instant risk assessment with visual feedback.

## Table of Contents
- [About](#about)
- [Features](#features)
- [Experimental Setup](#experimental-setup)
- [Screenshots](#screenshots)

## About
Diabetes can be better managed when detected early. This application aims to predict diabetes risk in patients by applying a Gradient Boosting machine learning model trained on health metrics including glucose levels, BMI, blood pressure, and other key indicators.

The model was trained on the Pima Indians Diabetes Dataset and achieves high accuracy in predicting diabetes risk, enabling early intervention and better healthcare outcomes.

## Features
- **User-Friendly Interface**: Clean, intuitive design with custom CSS styling
- **Real-time Input Validation**: Automatic formatting and cleaning of input values
- **Instant Predictions**: Get diabetes risk assessment with probability score
- **Responsive Design**: Works on desktop and mobile devices
- **Visual Feedback**: Interactive UI with visual cues and tooltips
- **Form Reset**: Easy reset functionality for multiple predictions

## Experimental Setup

### Web Application Development
- **IDE**: Visual Studio Code
- **Framework**: Streamlit (Python web application framework)
- **Frontend**: Streamlit components with custom HTML/CSS
- **Backend**: Python with Streamlit framework

### Model Training & Development
- **Platform**: Google Colab (for model training and experimentation)
- **Environment**: Google Colab
- **Language**: Python 3.x
- **Machine Learning Libraries**:
  - scikit-learn (Gradient Boosting Classifier)
  - pandas (data manipulation)
  - numpy (numerical operations)
  - joblib (model serialization)
- **Data Visualization**: matplotlib, seaborn
